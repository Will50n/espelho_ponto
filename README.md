# Buscador de Espelho de ponto automático.

## Passo a passo para instalação:

- Verificar se o computador tem o Node.js intalador. Se não tiver, instalar.
- Instalar bibliotecas: Abrir o terminal, navegar até a pasta do programa e rodar `npm install`.
- Editar o arquivo `.env` com as credenciais do usuário.
- Clicar duas vezes no arquivo `executar_espelho_ponto.bat`.

Pronto, deverá ser criado um pdf com os registros de ponto disponíveis.
